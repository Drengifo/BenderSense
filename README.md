# BenderSense

**BenderSense** es una solución desarrollada por **LoRe Ingeniería** para la adquisición, visualización y análisis de ensayos con Bender Elements.

> Software desarrollado por LoRe Ingeniería. Todos los derechos reservados.

## Descargar BenderSense para Windows

La aplicación se distribuye como ejecutable portable para Windows. No es necesario instalar Python ni librerías adicionales.

### [⬇ Descargar BenderSense para Windows](https://github.com/Drengifo/BenderSense/releases)

En la página de la versión más reciente, descarga el archivo `.exe` disponible en la sección **Assets**.

## Requisitos

- Windows 10 u 11 de 64 bits.
- Equipo BenderSense.
- Conexión USB entre el equipo y el computador.

## Uso rápido

1. Descarga la última versión desde **Releases**.
2. Guarda `BenderSense.exe` en una carpeta de tu computador.
3. Conecta el equipo BenderSense mediante USB.
4. Ejecuta `BenderSense.exe`.
5. En la aplicación, selecciona el puerto correspondiente y presiona **CONECTAR**.
6. Ingresa el nombre del ensayo y la distancia entre los Bender Elements.
7. Presiona **EJECUTAR ENSAYO**.

La aplicación permite visualizar las señales emitida y recibida, ajustar la visualización de la señal recibida, utilizar cursores para el análisis temporal y guardar los ensayos para revisión posterior.

## Calibración

Desde el menú **CALIBRACIÓN** se encuentran disponibles las herramientas de:

- Pulso único.
- Ráfaga de 10 ciclos.
- Calibración en vivo.
- Guardado de capturas de calibración.

Estas funciones permiten comprobar la respuesta del sistema y realizar ajustes antes de ejecutar el ensayo definitivo.

## Archivos de ensayo

Por defecto, BenderSense guarda la configuración y los ensayos en:

```text
Documentos\LoReING\BenderSense\
```

Los ensayos se almacenan dentro de:

```text
Documentos\LoReING\BenderSense\Ensayos\
```

Los datos guardados pueden volver a abrirse desde la aplicación para revisar el ensayo y modificar los cursores sin repetir la adquisición.

## Aviso de Windows

BenderSense se distribuye actualmente como una aplicación portable sin firma digital de editor.

Windows SmartScreen puede mostrar una advertencia la primera vez que se ejecuta el programa. Verifica siempre que el archivo haya sido descargado desde este repositorio oficial antes de ejecutarlo.
